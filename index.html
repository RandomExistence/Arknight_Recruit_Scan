    Advanced OCR Settings
    900 ms

    How often a frame is captured and OCR'd. Lower = updates feel snappier but costs more CPU per second; raise it if scanning feels laggy or the phone gets warm. Default: 900 ms.

    900 px

    The frame is downscaled to this width before OCR. Higher preserves more detail (useful if text looks small or blurry) but slows every scan down; lower is faster but can start losing thin letterforms. Default: 900 px.

    170

    Cutoff (0–255) used to turn the frame black & white before OCR — pixels brighter than this become the white text Tesseract reads. Lower it if tags are getting missed in a dim or glary room; raise it if background noise is being picked up as text. Default: 170.

    0.22

    How much OCR noise a tag can have and still count as a match, as a fraction of the tag's own length. Raise it to catch messier OCR (but short tags like AoE/DPS risk false positives); lower it to be stricter. Default: 0.22.
